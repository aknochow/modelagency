How to read these scores

BenchLM columns are source-owned values and link to their evidence. Overall is BenchLM’s published overall score; Agentic and the three core benchmark columns are separate, not interchangeable. Quality cards rank the selected source scores even when the winner is over budget, while Best Value, Daily Driver Fit, and the workload mix stay budget-aware; over-budget quality winners are labeled explicitly. Score ranges show observed configurations only, with no effort interpolation. Monthly API estimates use your input and output token assumptions. The comparison table keeps all selected models visible.

BenchLM publishes the canonical benchmark values. modelagency derives work categories, Daily Driver, and value recommendations from those values when available.
